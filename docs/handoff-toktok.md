# ТокТок туслах — TokTok-ийн техникийн багт хүлээлгэж өгөх заавар

Энэ баримт бичигт TokTok-ийн техникийн баг "ТокТок туслах" чатботыг өөрсдийн AWS орчинд асааж,
хүргэгч, ресторан, операторын системд залгахад хийх ажлыг алхам алхмаар бичив.

---

## 1. Тойм

Чатбот нь TokTok-ийн системээс **тусдаа** ажилладаг хоёр үйлчилгээ (backend, frontend) болон
гурван өгөгдлийн сангаас бүрдэнэ. TokTok-ийн одоогийн код, өгөгдлийн санг өөрчлөхгүй. Зөвхөн
хуудсуудад жижиг холбоос нэмнэ.

```
 client.toktok.mn / order.toktok.mn ──(widget.js: чатын дүрс)──┐
 Toktok Driver апп ──("Тусламж" товч → WebView /embed)─────────┤
 cc.toktok.mn ──(цэс: "ТокТок туслах" → /operator)─────────────┤
                                                               ▼
                     chat.toktok.mn  ── frontend (Next.js, порт 3000)
                     chat-api.toktok.mn ── backend (FastAPI, порт 8000)
                                   │
          ┌────────────────────────┼─────────────────────────┐
     PostgreSQL 16 + pgvector     Redis 7                Qdrant 1.19
     (үндсэн өгөгдөл)             (идэвхтэй яриа, 24 цаг)  (хайлтын индекс)
                                   │
                         AI загвар (Claude эсвэл Gemini API)
```

| Хэсэг | Хэн ашиглах | Хаяг |
|---|---|---|
| Чатын цонх (popup / апп) | Хүргэгч, ресторан | `/embed` (widget.js дотроос нээгдэнэ) |
| Операторын самбар | Оператор | `/operator`: чат, мэдлэгийн сан, ботын заавар |
| Админы самбар | Админ | `/admin`: батлах, ажилтан, үзүүлэлт, аудит |

## 3. Шат дараалал

| Шат | Юу ажиллах | TokTok-оос шаардах зүйл |
|---|---|---|
| **1-р шат** (`GATEWAY_MODE=faq_only`) | Журам, FAQ-д хариулах, оператор руу шилжүүлэх | Сервер, өгөгдлийн сан, скрипт нэмэх. **Хэрэглэгчийн токен хэрэггүй** |
| **2-р шат** | Хүргэгчийн профайл, идэвхтэй захиалга, рестораны тооцоо, хүсэлт илгээх | Хэрэглэгч таних + өгөгдлийн API (5-р хэсэг) |

1-р шатанд бот хэрэглэгчийн хувийн мэдээлэлд **огт** хандахгүй. "Миний захиалга хаана байна"
гэх мэт асуултад аппын хаанаас харахыг зааж, эсвэл оператор руу шилжүүлнэ. Хэрэглэгч бүрийг
хөтөч бүрт санамсаргүйгээр үүсгэсэн нэргүй дугаараар (`anon:<төрөл>:<санамсаргүй id>`) ялгадаг.
Энэ дугаар хэн болохыг илэрхийлэхгүй, зөвхөн хоёр хүний яриаг хооронд нь холихгүй байх зорилготой.

## 4. AWS дээр бэлдэх зүйлс

### 4.1 Өгөгдлийн сан
| Үйлчилгээ | Зөвлөмж | Тэмдэглэл |
|---|---|---|
| PostgreSQL 16 | Amazon RDS for PostgreSQL | `vector` (pgvector) өргөтгөл идэвхжүүлэх эрхтэй хэрэглэгч. Хүснэгтүүдийг backend өөрөө үүсгэнэ |
| Redis 7 | Amazon ElastiCache for Redis | Идэвхтэй ярианы төлөв (24 цаг), түгжээ, хурдны хязгаар |
| Qdrant 1.19 | ECS дээр контейнер (EFS volume) эсвэл Qdrant Cloud | Хайлтын индекс. PostgreSQL-ээс дахин үүсгэх боломжтой тул нөөцлөх шаардлагагүй |

### 4.2 Үйлчилгээнүүд
- `backend/Dockerfile`, `frontend/Dockerfile`-аас image бүтээж ECS (Fargate) эсвэл EKS дээр ажиллуулна.
- Frontend image бүтээхэд дараах build argument өгнө:
  - `NEXT_PUBLIC_API_BASE_URL=https://chat-api.toktok.mn`
  - `NEXT_PUBLIC_EMBED_PARENT_ORIGINS=https://client.toktok.mn,https://order.toktok.mn,https://kitchen.toktok.mn,https://cc.toktok.mn`
- Ачааллын тэнцвэржүүлэгчийн (ALB) health check: `GET /api/health` → `{"ok": true}`.
- HTTPS заавал. Домэйн: `chat.toktok.mn` (frontend), `chat-api.toktok.mn` (backend). Route 53 дээр бүртгэнэ.
- Хариулт урсгал (SSE) хэлбэрээр ирдэг тул ALB-ийн idle timeout-ийг 120 секундээс доошгүй болгоно.
- Backend-ийг хэд хэдэн хуулбараар зэрэг ажиллуулж болно. Хуулбарууд Redis, PostgreSQL-ээр дамжиж хоорондоо холбогдоно.

### 4.3 Тохиргоо (backend орчны хувьсагч)
Нууц утгуудыг AWS Secrets Manager-т хадгална.

| Хувьсагч | Утга | Тайлбар |
|---|---|---|
| `ENV` | `prod` | Аюулгүй байдлын шалгалтуудыг идэвхжүүлнэ (доороос харна уу) |
| `GATEWAY_MODE` | `faq_only` | 2-р шат хүртэл. Хуурамч өгөгдлийн горим (`mock`) prod-д хориотой |
| `DATABASE_URL` | `postgresql://…@…rds.amazonaws.com:5432/toktok_chatbot` | |
| `REDIS_URL` | `rediss://…cache.amazonaws.com:6379/0` | |
| `VECTOR_STORE` / `QDRANT_URL` / `QDRANT_API_KEY` | `qdrant` / `https://…` / … | |
| `LLM_PROVIDER` | `anthropic` (зөвлөж байна) эсвэл `gemini` | Төлбөртэй түлхүүр. Үнэгүй хувилбар ачаалал ихтэй, өгөгдлийг сургалтад ашиглаж болзошгүй |
| `ANTHROPIC_API_KEY` эсвэл `GEMINI_API_KEY` | нууц | |
| `AGENT_MODEL`, `CLASSIFIER_MODEL` | загварын нэр | `.env.example`-ийг харна уу |
| `OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET` | Microsoft Entra | 6-р хэсэг |
| `OIDC_REDIRECT_URI` | `https://chat-api.toktok.mn/api/auth/callback` | |
| `OIDC_ALLOWED_DOMAINS` | `["toktok.mn"]` | Зөвхөн энэ домэйны хаягаар нэвтэрнэ |
| `STAFF_BOOTSTRAP_ADMINS` | `["хариуцагч@toktok.mn"]` | Анхны админ. Бусдыг `/admin` → Ажилтнууд-аас нэмнэ |
| `STAFF_SESSION_SECRET` | 32+ тэмдэгт санамсаргүй | `openssl rand -hex 32` |
| `ADMIN_API_KEY`, `USER_REF_SALT` | санамсаргүй нууц | `USER_REF_SALT`-ийг дараа нь **бүү өөрчил** (хэрэглэгчийн хэш өөрчлөгдөнө) |
| `FRONTEND_BASE_URL` | `https://chat.toktok.mn` | |
| `CORS_ORIGINS` | `["https://chat.toktok.mn"]` | |
| `COOKIE_SECURE` | `true` | |
| `OPERATOR_PHONE_DRIVER` / `_CLIENT` | жинхэнэ дугаар | Ботын хариултанд харагдана |
| `RATE_LIMIT_PER_MINUTE` / `RATE_LIMIT_PER_IP_PER_MINUTE` | `20` / `120` | Хүн тус бүр / IP тус бүрийн хязгаар (мобайл сүлжээнд олон хүн нэг IP хуваалцдаг тул IP-ийнх өндөр) |
| `FORWARDED_ALLOW_IPS` | ALB-ийн дотоод сүлжээ (жишээ `10.0.0.0/8`) | uvicorn `--proxy-headers`-тэй хамт: хэрэглэгчийн жинхэнэ IP-г харах (IP хязгаарт хэрэгтэй) |
| `LANGFUSE_*` | заавал биш | Хариултын чанар, зардлын хяналт |

Frontend-ийн хувьсагч:

| Хувьсагч | Утга |
|---|---|
| `EMBED_ALLOWED_ORIGINS` | `'self' https://client.toktok.mn https://order.toktok.mn https://kitchen.toktok.mn https://cc.toktok.mn` |

**`ENV=prod` үед backend дараах тохиолдолд асахаас татгалзана:** нууц түлхүүрүүд анхны
утгаараа байх, SSO тохируулаагүй байх, AI-гүй горим (`fake`), хуурамч өгөгдлийн горим (`mock`),
`DATABASE_URL` эсвэл `REDIS_URL` хоосон байх. Энэ нь буруу тохиргоогоор санамсаргүй ажиллахаас хамгаална.

## 5. Хэрэглэгч таних ба TokTok-ийн өгөгдөл (2-р шат)

### 5.1 Хэрэглэгч таних
Хүргэгч эсвэл ресторан TokTok-ийн системд нэвтэрсэн байхад чатбот тэр хүн хэн болохыг найдвартай
мэдэх ёстой. Хөтчөөс ирсэн "би №501" гэсэн мэдээлэлд итгэх боломжгүй тул доорх хоёр аргын
аль нэгийг сонгоно.

**А) Гарын үсэгтэй токен (зөвлөж байна, хамгийн бага ажил)**
TokTok-ийн backend богино хугацаанд хүчинтэй JWT үүсгэж, хуудас түүнийг `widget.js`-д өгнө:
```json
{ "sub": "d-501", "role": "driver", "name": "Ганбаа", "exp": 1760500000 }
```
- Гарын үсэг: HS256 (хуваалцсан нууц) эсвэл RS256 (TokTok-ийн нийтийн түлхүүр).
- Хүчинтэй хугацаа: 10–30 минут.
- Чатбот талд энэ токеныг шалгах кодыг бид нэмнэ.

**Б) Таних API**
`GET /internal/chatbot/whoami` (Authorization: TokTok-ийн хэрэглэгчийн токен) →
`{ "role": "driver", "id": "d-501", "name": "Ганбаа" }`

### 5.2 Өгөгдлийн API
Чатботын TokTok-той холбогдох бүх код нэг файлд байна: `backend/app/tools/gateway.py`
(`TokTokGateway`). Доорх функцуудад тохирох API хэрэгтэй:

| Функц | Буцаах өгөгдөл | Хэрэглэгч |
|---|---|---|
| `get_driver(driver_id)` | Төлөв, бүс, үнэлгээ, бүртгэлийн дутуу алхмууд, бичиг баримтын төлөв, дүрэмт хувцасны шалгалт | Хүргэгч |
| `get_driver_active_orders(driver_id)` | Хуваарилагдсан захиалгууд, үе шат, авах газар, хүргэх бүс | Хүргэгч |
| `get_merchant(merchant_id)` | Салбарууд, апп дээр харагдах эсэх, ажиллах цаг, менежер | Ресторан |
| `get_settlement(merchant_id, period)` | Тухайн хугацааны тооцооны тойм | Ресторан |
| `create_merchant_request(merchant_id, type, details)` | Partner баг руу хүсэлт (цаг өөрчлөх, түр хаах, шинэ салбар, хэрэглэгч нэмэх, урамшуулал, цэс) → хүсэлтийн дугаар | Ресторан |

Шаардлага:
- Чатбот өөрийн үйлчилгээний түлхүүрээр дуудна. Хэрэглэгчийн ID-г **таних шатаас** авна, AI загвараас хэзээ ч авахгүй. Тиймээс нэг хэрэглэгч нөгөөгийн мэдээллийг харах боломжгүй.
- Хариу JSON, 2 секундээс хурдан.
- Өөрчлөлт хийх API (`create_merchant_request`) нь хэрэглэгч чатаар тусад нь баталсны дараа л дуудагдана.
- Шууд өгөгдлийн сангаас унших хувилбар боломжтой ч зөвлөхгүй. Тэгэх бол зөвхөн унших эрхтэй, тусдаа хэрэглэгч ашиглана.

API-ийн тодорхойлолтыг (URL, хариуны жишээ) өгмөгц бид `gateway.py`-г холбоод `GATEWAY_MODE`-ийг шинэ горимоор сольж тестэлнэ.

## 6. Ажилтны нэвтрэлт (Microsoft Entra ID / Microsoft 365)

1. Entra admin center → App registrations → New registration → "TokTok Chatbot Staff".
2. Redirect URI (Web): `https://chat-api.toktok.mn/api/auth/callback`.
3. Certificates & secrets → client secret үүсгэнэ.
4. Тохиргоо:
   - `OIDC_ISSUER=https://login.microsoftonline.com/<tenant-id>/v2.0`
   - `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`
5. `STAFF_BOOTSTRAP_ADMINS`-д анхны админы хаягийг бичнэ. Бусад ажилтныг тэр админ `/admin` → **Ажилтнууд**-аас нэмж, эрх олгоно.

| Эрх | Хаана | Юу хийх |
|---|---|---|
| Оператор | `/operator` | Хүнд шилжсэн чатад хариулах. Мэдлэгийн сан, ботын зааврын ноорог бичиж админд илгээх |
| Админ | `/admin` | Батлах, нийтлэх, буцаах. Ажилтан, үзүүлэлт, аудит |

## 7. Системүүдэд залгах

### 7.1 Ресторан: client.toktok.mn, order.toktok.mn, kitchen.toktok.mn
Хуудас бүрийн `</body>`-ийн өмнө нэмнэ:
```html
<script>
  window.TokTokChat = {
    origin: "https://chat.toktok.mn",
    persona: "client",
    // 2-р шатанд: getToken: async () => await fetch("/api/chatbot-token").then(r => r.text()),
  };
</script>
<script src="https://chat.toktok.mn/widget.js" async></script>
```
- Баруун доод буланд шар чатын дүрс гарна. Утасны өргөнд чат бүтэн дэлгэцээр нээгдэнэ.
- Эдгээр сайтад одоогоор iframe хориглох тохиргоо (CSP) байхгүйг шалгасан. Хэрэв дараа нэмбэл `script-src` болон `frame-src`-д `https://chat.toktok.mn`-ийг оруулна.

### 7.2 Хүргэгч: Toktok Driver апп
Хүргэгчийн вэб олдоогүй тул апп дотор нэмнэ:
1. Цэс эсвэл профайл хэсэгт **"Тусламж"** товч нэмнэ. Жолоо барьж байх үед харагдахаар хөвөгч товч хийхгүй.
2. Товч дарахад WebView-ээр `https://chat.toktok.mn/embed`-ийг бүтэн дэлгэцээр нээнэ.
3. Хуудас ачаалагдмагц токен дамжуулна:
   ```js
   window.postMessage({ type: "toktok-auth", token: "<токен>", persona: "driver" }, "*")
   ```
   1-р шатанд токен оронд `anon:driver:<төхөөрөмжийн санамсаргүй 32 тэмдэгт>` ашиглана.
4. Чатаас ирэх мессежийг сонсоно: `toktok-chat-close` (✕ дарсан → WebView хаах), `toktok-chat-unread` (`count`: хаалттай байхад операторын хариу ирсэн → товч дээр тоо харуулах).
   - React Native: `window.ReactNativeWebView.postMessage`
   - Flutter / Android: `TokTokNative` нэртэй JavaScript channel
   - iOS WKWebView: `webkit.messageHandlers.toktok`

### 7.3 Оператор: cc.toktok.mn
Call Center-ийн цэсэнд **"ТокТок туслах"** нэмж `https://chat.toktok.mn/operator`-ийг нээнэ.
Шинэ таб эсвэл iframe аль аль нь болно. Операторууд Microsoft 365 хаягаараа нэвтэрнэ.

### 7.4 Захиалагч (toktok.mn), одоохондоо зогссон
Дараа идэвхжүүлэх бол `toktok.mn`-ийн CSP-д өөрчлөлт хэрэгтэй. Одоо `frame-src` нь зөвхөн
өөрийн болон QPay, `script-src` нь гадны скрипт хориглодог. `https://chat.toktok.mn`-ийг хоёуланд нь нэмнэ.

## 8. Өгөгдөл, нууцлал, нөөцлөлт

- **Хадгалагдах зүйл** (PostgreSQL):
  - Яриа (`conversations`), асуулт-хариулт бүр (`turns`), үнэлгээ (`feedback`)
  - Оператор руу шилжсэн яриа (`escalations`, `handoff_messages`)
  - Мэдлэгийн сан ба ботын зааврын бүх хувилбар (`kb_*`, `prompt_*`)
  - Ажилтнууд, аудит лог
- **Хувийн мэдээлэл:** утас, регистр, картын дугаар зэргийг хадгалахаас өмнө автоматаар нууцална. Хэрэглэгчийн ID-г `USER_REF_SALT`-аар хэшлэж хадгална.
- **AI үйлчилгээ рүү илгээгдэх зүйл:** хэрэглэгчийн мессеж, мэдлэгийн сан. Гэрээ, хуулийн зөвшөөрлийг TokTok-ийн хуулийн талтай шийдэх хэрэгтэй.
- **Нөөцлөлт:** RDS-ийн автомат snapshot-ийг өдөр бүр, доод тал нь 7 хоног хадгална. Redis, Qdrant-ийг нөөцлөх шаардлагагүй.
- **Чатын түүх харах, анализ:** `/admin` → **Яриа**: шүүх (төрөл, огноо, оператор руу шилжсэн, 👎, текст), яриа бүрийг уншиж,
  **CSV (Excel)** татна. Татсан бүрийг аудит логт бүртгэнэ.
- **Хадгалах хугацаа:** одоо чатын түүхийг хязгааргүй хадгалдаг. TokTok хугацааг (жишээ нь 6 эсвэл 12 сар) шийдвэл автоматаар устгах ажлыг бид нэмнэ.
